MILLIE ANN JONES — PORTFOLIO WEBSITE

Files:
- index.html
- styles.css
- script.js
- assets/ (portfolio page images)

HOW TO USE:
1. Upload the whole folder to a static host such as GitHub Pages, Netlify, Cloudflare Pages, or another static web host.
2. Set index.html as the site's entry point.
3. Connect your custom domain through the host's domain/DNS settings.

The website is intentionally static: there is no database or server required.
The portfolio visuals are rendered from the supplied 24-page PDF.
